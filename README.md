## Design

The site is a **precision drafting sheet**: warm architectural paper, hairline rules,
one vermilion accent, and a technical drawing vocabulary — title blocks, dimension
lines, callout leaders, a legend and a title block frame.

- **Type** — Instrument Serif for display, Instrument Sans for text, IBM Plex Mono for
  data and annotation. Mono is only ever used for real data, never as decoration.
- **Palette** — paper `#F4F1EA`, ink `#1A1917`, vermilion `#B23A1C`. The Impact and
  Contact sections invert to an ink band so the page has a rhythm.
- **Sheet 00 — site plan** — `index.html` opens with a hand-drawn SVG plan of the
  actual homelab: consumer and public traffic terminates at the OPNsense router, which
  separates it from the VLAN-segmented server subnet (3 Proxmox nodes over Ceph, the
  local AI node, the media and private-cloud host). A Cloudflare tunnel reaches the
  game server inside the Proxmox cluster.
- **Measurements** — the charts are drawn from figures already published in the
  repositories: Project Maya prefill throughput by prompt depth, the Strata
  v0.1.32 → v0.1.39 decode comparison, the trading bot against equal-weight
  buy-and-hold, and the FFIOM audit findings by severity.

Every word, number, tag and link is carried over from the previous site. Nothing was
invented and no data was invented.

## Building

`index.html` is generated, so the content has a single source of truth:

```bash
python3 tools/build.py
```

- `tools/site-data.json` — the content, extracted verbatim from the previous site.
- `tools/svgs.py` — the site plan and the four charts.
- `tools/build.py` — renders `index.html` from the two.

The output is deterministic: running the build twice produces byte-identical HTML.
Edit the JSON (or the SVG builders) and re-run — never hand-edit `index.html`.

The gallery pages are hand-authored and share `assets/site.css`.

## Accessibility and behaviour

- Reveal animations are additive: content is visible by default and only ever moves.
  If JavaScript fails, the page still reads.
- `prefers-reduced-motion` disables the reveals, the count-up and the bar growth.
- All 43 text/background pairs meet WCAG AA; verified in-browser, not by eye.
- The project sheets are real `<details>` elements, so they work without JavaScript.
  A small script keeps only one open at a time.
- Print stylesheet flattens the page to black on white and expands every project.

## Checking a change

```bash
python3 -m http.server 8899 --bind 127.0.0.1   # serve the site
```

Then open `http://127.0.0.1:8899/`. Run `python3 tools/build.py` before serving if you
changed the JSON or the SVG builders.
